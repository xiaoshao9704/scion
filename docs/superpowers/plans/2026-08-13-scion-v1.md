# Scion v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建一条 `清单 + 目录扫描 → Plugin IR → 目标生态清单 → 安装注册` 的管线，把 Claude 插件转换并安装到 Kimi / Codex，且把所有有损项显式报告出来。

**Architecture:** 三段式。**正规化**读取任一生态的清单并扫描真实目录，产出带 provenance 的 Plugin IR；**投影**按目标 ecosystem profile（声明式数据，非代码）把 IR 渲染成目标清单与文件树；**安装**写入目标生态的插件根目录并更新其注册表。L3 工具名映射是生态对级别的常量表，与插件无关。doctor 贯穿全程，把 BLOCK/LOSS/INFO 汇总输出。

**Tech Stack:** TypeScript (ESM, NodeNext) + Node 20+，`zod` 校验 IR 与 profile，`gray-matter` 解析回写 frontmatter，`vitest` 单测与黄金样本 diff。CLI 参数用 Node 内置 `util.parseArgs`，不引入 commander。安装一律走目标生态自己的 CLI（`codex plugin ...`），不解析也不重写对方的配置文件。

**Spec:** [docs/superpowers/specs/2026-08-13-scion-design.md](../specs/2026-08-13-scion-design.md)

## Global Constraints

- Node ≥ 20（本机 v26.7.0）。`package.json` 设 `"type": "module"`，`"engines": {"node": ">=20"}`。
- 包名 `@scion/cli`，bin 名 `scion`，入口 `dist/cli.js`。
- TS 严格模式，`module: NodeNext`。**所有相对 import 必须带 `.js` 后缀**（ESM 要求），包括 `.ts` 源文件里的相对导入。
- 依赖只允许：`zod`、`gray-matter`（运行时）；`typescript`、`vitest`、`@types/node`（开发）。加任何其他依赖都视为超范围。
- 生态 id 常量固定为 `'claude' | 'kimi' | 'codex'`，类型名 `EcosystemId`。
- Kimi `name` 必须匹配 `^[a-z0-9][a-z0-9_-]{0,63}$`；不匹配 → BLOCK。
- Kimi 单字段上限 32768 字节，全部启用插件的指令总预算 65536 字节；`skillInstructions` 超限 → BLOCK。
- v1 **不转换 hooks**，只在 doctor 里报 LOSS；**不生成运行时垫片**；**不做反向转换**（Kimi/Codex → Claude）；**不做 marketplace 批量转换**。
- 任何有损转换都必须产出一条 `Finding`，禁止静默丢弃。这是本工具的主要产出之一。
- **不直接修改目标生态的配置文件。** 能用对方 CLI 完成的安装/注册，一律 shell out 给对方 CLI；scion 只写自己名下的目录（`~/.scion/**`）和目标生态的插件数据目录。唯一例外是 Kimi 的 `installed.json`（Kimi 无 plugin CLI），且必须显式 `--write-registry` 才写，并先备份再原子写（temp + rename）。
- 调用外部 CLI 一律用 `execFile`（不经 shell），参数以数组传入，禁止字符串拼接命令行。

## 已实测确认的事实（写死在 profile 里，不要再猜）

| 生态 | 清单路径 | 安装手段 |
|---|---|---|
| Claude | `.claude-plugin/plugin.json` | v1 只作转换源，不安装 |
| Kimi | `kimi.plugin.json` > `.kimi-plugin/plugin.json` | **无 plugin CLI**，只有 TUI 的 `/plugins` |
| Codex | `.codex-plugin/plugin.json` | `codex plugin marketplace add` + `codex plugin add` |

### 安装策略（本计划的核心约束）

`codex --help` / `kimi --help` 实测结论：

- **Codex 有完整 CLI。** `codex plugin add <PLUGIN>@<MARKETPLACE>`、`codex plugin marketplace add <SOURCE>`（SOURCE 可为本地路径）、`codex plugin list`、`codex plugin remove`、`codex plugin marketplace upgrade|remove`。所以 scion **不碰** `~/.codex/config.toml`、也不碰 `~/.codex/plugins/cache/`——那是 Codex CLI 自己的地盘。scion 只做一件事：在自己名下建一个本地 marketplace，然后把安装动作交给 `codex plugin add`。
- **Kimi 没有 plugin 子命令。** `kimi` 顶层只有 `export/provider/acp/web/server/login/doctor`；插件安装在 TUI 里通过 `/plugins` 完成（二进制里可见 `installPluginFromSource(host, source)` 与 `/plugin commands`）。因此 Kimi 侧默认**只转换、不安装**：产物落到 `~/.scion/out/<plugin>/kimi/`，并打印"在 Kimi 里运行 `/plugins` 从该路径安装"的指引。只有显式传 `--write-registry` 时，scion 才落盘到 `~/.kimi-code/plugins/managed/<id>/` 并写 `installed.json`（先备份再原子写）。

### Marketplace 怎么管

Scion 有**两条互不干扰**的产出路径：

- **单插件**（Task 18–19）：转换一个插件，挂在固定的本地 marketplace `scion` 下，交给 `codex plugin add` 安装。
- **整市场**（Task 22–24）：把一份 marketplace 清单连同它引用的插件整体转换，**保留原 marketplace 名**，产出本地目录（Codex）或单个 JSON 文件（Kimi）。产物是交付物，**scion 不自动注册**。

#### 三边 marketplace 格式（全部实测）

| | Claude `.claude-plugin/marketplace.json` | Codex `.agents/plugins/marketplace.json` | Kimi catalog（单 JSON 文件） |
|---|---|---|---|
| 市场名 | `name` | `name` | **无此字段** |
| 归属/展示 | `owner: {name}` | `interface: {displayName}` | — |
| 顶层版本 | — | — | `version` |
| 条目主键 | `plugins[].name` | `plugins[].name` | `plugins[].id` |
| 条目来源 | `source`（字符串） | `source: {source:"local", path}` | `source` / `url` / `downloadUrl`（字符串） |
| 条目描述 | `description` | — | `description` / `shortDescription` |
| 条目其他 | — | `policy{installation,authentication}`、`category` | `displayName`/`name`、`version`、`homepage`/`websiteURL`、`keywords[]`、`tier`、`type` |

Kimi 侧的解析规则（从二进制里 `parsePluginMarketplace` / `parseMarketplaceEntry` 读出）：顶层必须是对象且含 `plugins` 数组；每个条目 `id` 与 `source` 必填；相对 `source` 按 **catalog 文件所在目录**解析；`displayName` 缺省回落到 `name` 再回落到 `id`；`type` 只接受 `plugin`（`managed`/`guide` 为兼容别名）。catalog 位置由 `KIMI_CODE_PLUGIN_MARKETPLACE_URL` 环境变量或 TUI 里 `/plugins <source>` 指定，本地路径与 http(s) URL 都接受。

#### 统一的目录布局

所有 marketplace 相关产物都在 `~/.scion/markets/` 下，**生态永远是路径的一段**：

```
~/.scion/markets/
├── scion/codex/                     # scion 自建市场（裸插件安装的兜底包装）
│   ├── .agents/plugins/marketplace.json
│   └── plugins/<插件>/
└── <原市场名>/                       # 整市场转换的产物
    ├── codex/                       # Codex 要目录形态
    │   ├── .agents/plugins/marketplace.json
    │   └── plugins/<插件>/
    └── kimi/
        └── marketplace.json         # Kimi 要单文件形态
```

「怎么区分 Codex 和 Kimi 的市场」的答案就是**看路径里的生态段**。scion 自建市场不再是特例，它只是一个恰好叫 `scion` 的市场。

#### 实测：Codex 的注册名取自文件，不是目录

用目录名与文件内 `name` 故意不同的一次性市场探测（目录 `scion-probe-DIRNAME`，文件内 `"name": "scion-probe-FIELDNAME"`）：

```
Added marketplace `scion-probe-FIELDNAME` from .../scion-probe-DIRNAME

[marketplaces.scion-probe-FIELDNAME]
source = ".../scion-probe-DIRNAME"
```

**注册键取自 `marketplace.json` 的 `name` 字段；目录名只被记成 `source` 路径，不参与命名。** 三个推论：

1. `--as <name>` 必须**改写产物文件的 `name` 字段**，改目录名无效。
2. 模式 A（本地消费别人的市场）与模式 B（写回自己仓库）**无法共用同一份产物**——它们要求同一字段取不同的值。所以改名只能是**转换时**的选择，不能延后到注册时。
3. 冲突检测可靠：名字由 scion 自己写入，执行注册命令**之前**就能与 `codex plugin marketplace list` 的现有市场比对，不必等 Codex 报错。

#### 「marketplace 名不变」如何成立

- **Codex**：`name` 字段原样写入产物的 `marketplace.json`，一个字符不改。
- **Kimi**：catalog 格式里**根本没有市场名字段**，市场身份就是那个 JSON 文件的位置。所以名字只体现在输出路径 `~/.scion/markets/<name>/kimi/marketplace.json` 上——doctor 对此报一条 INFO，说明"该生态无处承载市场名"。

**关键：scion 不替用户注册整市场。** Codex 的 `config.toml` 里 marketplace 是**按名字做键**的（`[marketplaces.team-skills]`）。若用原名把一个新 root 注册进去，就是同一个键换 `source`，会覆盖用户原有条目。所以整市场转换只产出文件，并打印下一步命令让用户自己决定：

```bash
# Codex：注意这会覆盖 config.toml 里同名的既有条目
codex plugin marketplace add ~/.scion/markets/<name>/codex
# Kimi：指向 catalog 文件即可，无需注册
KIMI_CODE_PLUGIN_MARKETPLACE_URL=~/.scion/markets/<name>/kimi/marketplace.json kimi
```

#### 单插件路径下的 marketplace 规则

**为什么要自建市场？** 因为 `codex plugin add` 的签名是 `<PLUGIN>@<MARKETPLACE>`——它**没有「从某个目录装一个插件」的用法**（帮助原文：*Install a plugin from a configured marketplace snapshot*）。在「优先用对方 CLI」+「不改对方配置文件」两条约束下，把转换产物包装成一个最小市场是唯一的路。裸插件来源（`./my-plugin`、`owner/repo`）本来就没有市场可转，也只能这样。

**1. 只建一个，名字固定为 `scion`。** 每执行一次 `codex plugin marketplace add` 就往 `config.toml` 加一个 `[marketplaces.*]` 段；一源一个的话 N 个来源就是 N 段。所有单插件产物统一挂 `scion` 下，用户配置只多一段。

代价是**来源信息丢失**——`codex plugin list` 里所有 scion 装的插件都显示为 `<name>@scion`，看不出原本来自哪。缓解办法是把原始来源记进 `marketplace.json` 条目自身（而非 `config.toml`），`scion list` 也显示来源；这样来源可查而用户配置仍只多一段。

**源本身带市场时，更好的做法是转换那个市场**（`scion market convert`），注册后用真实市场名安装，来源自然保住。自建市场是裸插件的兜底，不是唯一路径。

**2. 它是持久资产，不是临时暂存。** 实测 `codex plugin marketplace list`：

```
team-skills              /Users/you/code/team-skills
claude-plugins-official  /Users/you/.codex/.tmp/marketplaces/claude-plugins-official
```

本地来源是**活引用**（root 就是原路径），只有 git 来源才快照到 `.tmp/marketplaces/`。所以 `~/.scion/markets/scion/codex/` 一旦被清理，Codex 侧立刻悬空。它必须长期存在、纳入 `scion list`、只能由 `scion remove` 清理。

**3. 插件名冲突必须显式拦截。** 选择器 `name@marketplace` 有命名空间，但插件自身的 `name` 决定 skill / command 的命名空间。本机现状即活例：`superpowers@openai-curated` 已安装，再装同名的会撞。安装前查重，撞了报 BLOCK 并提示 `--as <new-name>`。

**4. 查重用「CLI 拿位置、JSON 拿数据」。** `codex plugin list` 按 marketplace 分组、列宽对齐，解析一碰就碎。改为 `codex plugin marketplace list` 取 root（两列，第一列无空格，按首个空白切分），再读该 root 下的 `.agents/plugins/marketplace.json` 或 `.claude-plugin/marketplace.json`，从 JSON 取插件名。

版本策略：marketplace 里每个插件只留一份最新的，多版本缓存由 Codex 按 `<name>/<version>/` 自己管。

- [ ] **Step 4: 写最小实现**

`src/cli.ts`：

```typescript
#!/usr/bin/env node
import { readFile } from 'node:fs/promises';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

export interface CliIo {
  write: (s: string) => void;
}

const COMMANDS = ['install', 'convert', 'doctor', 'list', 'sync'] as const;

export async function runCli(argv: string[], io: CliIo): Promise<number> {
  const [first] = argv;

  if (first === '--version' || first === '-v') {
    const here = dirname(fileURLToPath(import.meta.url));
    const pkg = JSON.parse(await readFile(join(here, '..', 'package.json'), 'utf8'));
    io.write(`${pkg.version}\n`);
    return 0;
  }

  if (!first || first === '--help' || first === '-h') {
    io.write(usage());
    return first ? 0 : 1;
  }

  if (!(COMMANDS as readonly string[]).includes(first)) {
    io.write(`scion: unknown command '${first}'\n\n${usage()}`);
    return 1;
  }

  io.write(`scion: '${first}' not implemented yet\n`);
  return 1;
}

function usage(): string {
  return [
    'Usage: scion <command> [options]',
    '',
    '  install <github|path|zip> --to codex,kimi   拉取 → 转换 → 安装 → 写注册表',
    '  convert <dir> --to kimi [-o <dir>]          只转换，不安装',
    '  doctor <dir> [--to kimi]                    兼容性报告',
    '  list                                        已装插件',
    '  sync [<name>]                               上游更新后重新转换安装',
    '',
  ].join('\n');
}

if (process.argv[1] && import.meta.url === `file://${process.argv[1]}`) {
  runCli(process.argv.slice(2), { write: (s) => process.stdout.write(s) })
    .then((code) => { process.exitCode = code; });
}
```

```typescript
  skillInstructions: z.string().optional(),

  systemPromptPath: z.string().optional(),

  const parsed = PluginIRSchema.safeParse(value);
  if (!parsed.success) {
```

```typescript
  mcpServers: McpNotation;
  /** external-file / path-ref 时的文件名，相对插件根 */
  mcpServersFile?: string;
  /** 清单里 presentation 块的键名；null 表示该生态没有此块 */
  presentationKey: string | null;
  /** presentation 允许出现的字段白名单，超出的字段转出时丢弃并报 INFO */
  presentationFields: string[];
  /** 清单里 runtime 块允许的字段 */
  runtimeFields: string[];
}

export interface ConventionDirs {
  skills: string;
  commands: string;
  agents: string;
}

/** 单个 frontmatter 字段的映射规则 */
export interface FrontmatterRule {
  /** 目标字段名；null 表示目标端无对应字段 */
  to: string | null;
  /** 值映射表；缺省表示值直通 */
  valueMap?: Record<string, string>;
  lossy: boolean;
  /** lossy 为 true 时用于生成 Finding 的说明 */
  note?: string;
}

export interface FrontmatterMap {
  agents: Record<string, FrontmatterRule>;
  commands: Record<string, FrontmatterRule>;
}

export type PathVarStrategy =
  | { kind: 'keep' }
  | { kind: 'rename'; to: string }
  /** 去掉变量前缀，改为相对插件根的路径；有损，因为依赖运行时 cwd */
  | { kind: 'relativize' };

/**
 * 安装策略。原则：能用目标生态自己的 CLI 就用 CLI，绝不代替它改配置文件。
 * - codex-cli：scion 只在自己的目录下摆一个本地 marketplace，其余交给 `codex plugin`。
 * - kimi-managed：Kimi 没有 plugin CLI（只有 TUI 的 /plugins），只能落盘 + 可选写注册表。
 * - unsupported：v1 不支持往该生态安装（Claude 只作为源）。
 */
export type InstallStrategy =
  | {
      kind: 'codex-cli';
      /** scion 维护的本地 marketplace 名 */
      marketplaceName: string;
      /** 相对 $HOME，marketplace 根目录 */
      marketplaceRoot: string;
    }
  | {
      kind: 'kimi-managed';
      /** 相对 $HOME，支持 <plugin> 占位符 */
      rootTemplate: string;
      /** 相对 $HOME 的注册表路径；默认不写，需 --write-registry */
      registryPath: string;
    }
  | { kind: 'unsupported'; reason: string };

export interface InstallSpec {
  strategy: InstallStrategy;
}

export interface EcosystemProfile {
  id: EcosystemId;
  /** 候选清单路径，按优先级从高到低 */
  manifestPaths: string[];
  conventions: ConventionDirs;
  fieldDialect: FieldDialect;
  frontmatterMap: FrontmatterMap;
  /** 该生态自己的路径变量；null 表示没有 */
  pathVar: string | null;
  /** 从其他生态转入时如何处理对方的路径变量 */
  pathVarStrategy: PathVarStrategy;
  /** name 的正则约束（源字符串）；undefined 表示无约束 */
  namePattern?: string;
  limits: { fieldBytes?: number; totalInstructionBytes?: number };
  install: InstallSpec;
```

```typescript
import { basename, resolve } from 'node:path';
import type { PluginIR, PluginIdentity, Provenance } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import { emptyIR } from '../ir/schema.js';
import { findManifest } from './manifest.js';

export { findManifest } from './manifest.js';
export type { FoundManifest } from './manifest.js';

const IDENTITY_STRING_FIELDS = [
  'version',
  'description',
  'homepage',
  'repository',
  'license',
] as const;

export async function normalize(root: string, profile: EcosystemProfile): Promise<PluginIR> {
  const abs = resolve(root);
  const found = await findManifest(abs, profile);
  if (!found) {
    throw new Error(
      `no ${profile.id} manifest found in ${abs} (looked for: ${profile.manifestPaths.join(', ')})`,
    );
  }

  const ir = emptyIR(abs, profile.id);
  const prov = ir.provenance;
  const raw = found.raw;

  if (typeof raw.name === 'string' && raw.name.length > 0) {
    ir.identity.name = raw.name;
    push(prov, 'identity.name', 'manifest', found.path);
  } else {
    ir.identity.name = basename(abs);
    push(prov, 'identity.name', 'convention', 'derived from directory name');
  }

  for (const field of IDENTITY_STRING_FIELDS) {
    const value = raw[field];
    if (typeof value === 'string') {
      (ir.identity as Record<string, unknown>)[field] = value;
      push(prov, `identity.${field}`, 'manifest', found.path);
    }
  }

  if (Array.isArray(raw.keywords)) {
    ir.identity.keywords = raw.keywords.filter((k): k is string => typeof k === 'string');
    push(prov, 'identity.keywords', 'manifest', found.path);
  }

  const author = raw.author;
  if (author && typeof author === 'object' && !Array.isArray(author)) {
    const a = author as Record<string, unknown>;
    const out: NonNullable<PluginIdentity['author']> = {};
    for (const k of ['name', 'email', 'url'] as const) {
      if (typeof a[k] === 'string') out[k] = a[k] as string;
    }
    ir.identity.author = out;
    push(prov, 'identity.author', 'manifest', found.path);
  } else if (typeof author === 'string') {
    ir.identity.author = { name: author };
    push(prov, 'identity.author', 'manifest', `${found.path} (string form)`);
  }

  return ir;
}

function push(
  list: Provenance[],
  field: string,
  source: Provenance['source'],
  detail?: string,
): void {
  list.push({ field, source, detail });
}
```

```typescript
import { readdir, stat } from 'node:fs/promises';
import { join } from 'node:path';
import type { CapabilityDir, Finding, Provenance } from '../ir/types.js';

export type CapabilityKind = 'skills' | 'commands' | 'agents';

export interface ScanResult {
  dir: CapabilityDir | null;
  provenance: Provenance | null;
  issues: Finding[];
}

/** 把 "./lib/skills/" 之类统一成 "lib/skills/" */
export function normalizeDirPath(raw: string): string {
  const trimmed = raw.replace(/^\.\//, '').replace(/\/+$/, '');
  return trimmed.length === 0 ? '' : `${trimmed}/`;
}

export async function scanCapabilityDir(
  root: string,
  declared: string | undefined,
  conventionDir: string,
  kind: CapabilityKind,
): Promise<ScanResult> {
  const isDeclared = typeof declared === 'string' && declared.length > 0;
  const rel = normalizeDirPath(isDeclared ? declared : conventionDir);
  const abs = join(root, rel);

  let names: string[];
  try {
    names = await readdir(abs);
  } catch {
    if (isDeclared) {
      return {
        dir: null,
        provenance: null,
        issues: [
          {
            level: 'BLOCK',
            code: 'capability.declared-missing',
            message: `清单声明了 ${kind}: "${declared}"，但目录不存在`,
            where: rel,
          },
        ],
      };
    }
    // 约定目录不存在 = 该插件没有这类能力，不是问题
    return { dir: null, provenance: null, issues: [] };
  }

  const entries: string[] = [];
  for (const name of names.sort()) {
    if (name.startsWith('.')) continue;
    const info = await stat(join(abs, name));
    // skills 是一个目录一个技能；commands / agents 是一个 .md 一个条目
    if (kind === 'skills' ? info.isDirectory() : info.isFile() && name.endsWith('.md')) {
      entries.push(name);
    }
  }

  return {
    dir: { path: rel, entries },
    provenance: {
      field: `capabilities.${kind}`,
      source: isDeclared ? 'manifest' : 'convention',
      detail: isDeclared ? `declared as "${declared}"` : `scanned ${rel}`,
    },
    issues: [],
  };
}

/** hooks 只登记不解析；v1 不转换 */
export async function scanHooks(root: string): Promise<string[]> {
  const rel = 'hooks';
  let names: string[];
  try {
    names = await readdir(join(root, rel));
  } catch {
    return [];
  }
  const out: string[] = [];
  for (const name of names.sort()) {
    if (name.startsWith('.')) continue;
    const info = await stat(join(root, rel, name));
    if (info.isFile()) out.push(`${rel}/${name}`);
  }
  return out;
}
```

```typescript
import { readFile } from 'node:fs/promises';
import { join } from 'node:path';
import type { Finding, McpServerConfig, Provenance } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';

export interface McpReadResult {
  servers: Record<string, McpServerConfig>;
  provenance: Provenance | null;
  issues: Finding[];
}

/** .mcp.json 既可能是 { mcpServers: {...} } 也可能直接是 {...} */
function unwrap(parsed: unknown): Record<string, McpServerConfig> {
  if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed)) return {};
  const obj = parsed as Record<string, unknown>;
  const inner = obj.mcpServers;
  const target = inner && typeof inner === 'object' && !Array.isArray(inner) ? inner : obj;
  return target as Record<string, McpServerConfig>;
}

async function readFromFile(
  root: string,
  rel: string,
  declared: boolean,
): Promise<McpReadResult> {
  let text: string;
  try {
    text = await readFile(join(root, rel), 'utf8');
  } catch {
    if (!declared) return { servers: {}, provenance: null, issues: [] };
    return {
      servers: {},
      provenance: null,
      issues: [
        {
          level: 'BLOCK',
          code: 'mcp.declared-missing',
          message: `清单引用了 mcpServers: "${rel}"，但文件不存在`,
          where: rel,
        },
      ],
    };
  }

  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch (err) {
    return {
      servers: {},
      provenance: null,
      issues: [
        {
          level: 'BLOCK',
          code: 'mcp.parse-error',
          message: `无法解析 ${rel}: ${(err as Error).message}`,
          where: rel,
        },
      ],
    };
  }

  return {
    servers: unwrap(parsed),
    provenance: { field: 'capabilities.mcpServers', source: 'manifest', detail: rel },
    issues: [],
  };
}

export async function readMcpServers(
  root: string,
  raw: Record<string, unknown>,
  profile: EcosystemProfile,
): Promise<McpReadResult> {
  const declared = raw.mcpServers;

  if (declared && typeof declared === 'object' && !Array.isArray(declared)) {
    return {
      servers: unwrap(declared),
      provenance: { field: 'capabilities.mcpServers', source: 'manifest', detail: 'inline' },
      issues: [],
    };
  }

  if (typeof declared === 'string') {
    return readFromFile(root, declared.replace(/^\.\//, ''), true);
  }

  // 未在清单声明：Claude 靠外部 .mcp.json 约定
  if (profile.fieldDialect.mcpServers === 'external-file' && profile.fieldDialect.mcpServersFile) {
    return readFromFile(root, profile.fieldDialect.mcpServersFile, false);
  }

  return { servers: {}, provenance: null, issues: [] };
}
```

```typescript
import type { PluginIR } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import type { EmittedFile } from './types.js';

export function projectMcpServers(
  ir: PluginIR,
  target: EcosystemProfile,
): { manifestValue: unknown | undefined; files: EmittedFile[] } {
  const servers = ir.capabilities.mcpServers;
  if (Object.keys(servers).length === 0) return { manifestValue: undefined, files: [] };

  const body = `${JSON.stringify({ mcpServers: servers }, null, 2)}\n`;

  switch (target.fieldDialect.mcpServers) {
    case 'inline':
      return { manifestValue: servers, files: [] };
    case 'path-ref': {
      const file = target.fieldDialect.mcpServersFile ?? '.mcp.json';
      return { manifestValue: `./${file}`, files: [{ path: file, content: body }] };
    }
    case 'external-file': {
      const file = target.fieldDialect.mcpServersFile ?? '.mcp.json';
      return { manifestValue: undefined, files: [{ path: file, content: body }] };
    }
  }
}
```

`src/project/manifest.ts`：

```typescript
import type { Finding, PluginIR } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import type { EmittedFile } from './types.js';
import { projectMcpServers } from './mcp.js';

const IDENTITY_ORDER = [
  'name',
  'version',
  'description',
  'author',
  'homepage',
  'repository',
  'license',
  'keywords',
] as const;

export function projectManifest(
  ir: PluginIR,
  target: EcosystemProfile,
): { manifest: Record<string, unknown>; files: EmittedFile[]; findings: Finding[] } {
  const manifest: Record<string, unknown> = {};
  const findings: Finding[] = [];

  for (const field of IDENTITY_ORDER) {
    const value = (ir.identity as Record<string, unknown>)[field];
    if (value !== undefined) manifest[field] = value;
  }

  for (const kind of ['skills', 'commands', 'agents'] as const) {
    const dir = ir.capabilities[kind];
    if (dir) manifest[kind] = `./${dir.path}`;
  }

  const mcp = projectMcpServers(ir, target);
  if (mcp.manifestValue !== undefined) manifest.mcpServers = mcp.manifestValue;

  if (ir.capabilities.hooks.length > 0) {
    findings.push({
      level: 'LOSS',
      code: 'hooks.not-converted',
      message: `${ir.capabilities.hooks.length} 个 hooks 文件未转换（v1 不做 hooks 转换）：${ir.capabilities.hooks.join(', ')}`,
      where: 'hooks/',
    });
  }

  return { manifest, files: mcp.files, findings };
}
```

`src/project/index.ts`：

```typescript
import type { PluginIR } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import type { ProjectionResult } from './types.js';
import { projectManifest } from './manifest.js';

export type { EmittedFile, ProjectionResult } from './types.js';

export function project(ir: PluginIR, target: EcosystemProfile): ProjectionResult {

  return {
    manifest,
    manifestPath: target.manifestPaths[0],
    files,
    findings,
  };
}
```

```typescript
import matter from 'gray-matter';
import type { Finding } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';

export interface RemapResult {
  content: string;
  findings: Finding[];
}

export type FrontmatterKind = 'agents' | 'commands';

export function remapFrontmatter(
  source: string,
  kind: FrontmatterKind,
  from: EcosystemProfile,
  to: EcosystemProfile,
  where: string,
): RemapResult {
  const parsed = matter(source);
  const findings: Finding[] = [];

  // gray-matter 对无 frontmatter 的文件返回空 data，此时原样返回，避免平白加上 "---"
  if (Object.keys(parsed.data).length === 0) {
    return { content: source, findings };
  }

  const sourceRules = from.frontmatterMap[kind];
  const targetRules = to.frontmatterMap[kind];
  const out: Record<string, unknown> = {};

  for (const [field, value] of Object.entries(parsed.data)) {
    if (!(field in sourceRules)) {
      findings.push({
        level: 'INFO',
        code: 'frontmatter.field-unknown',
        message: `${from.id} profile 未声明 ${kind} 字段 "${field}"，按原样保留`,
        where: `${where}#${field}`,
      });
      out[field] = value;
      continue;
    }

    const rule = targetRules[field];

    if (!rule || rule.to === null) {
      findings.push({
        level: 'LOSS',
        code: 'frontmatter.field-dropped',
        message: rule?.note ?? `${to.id} 无对应字段，"${field}" 被丢弃`,
        where: `${where}#${field}`,
      });
      continue;
    }

    if (rule.valueMap && typeof value === 'string') {
      const mapped = rule.valueMap[value];
      if (mapped === undefined) {
        findings.push({
          level: 'LOSS',
          code: 'frontmatter.value-unmapped',
          message: `"${field}: ${value}" 在 ${to.id} 没有对应取值，字段被丢弃`,
          where: `${where}#${field}`,
        });
        continue;
      }
      out[rule.to] = mapped;
      findings.push({
        level: rule.lossy ? 'LOSS' : 'INFO',
        code: 'frontmatter.value-mapped',
        message: rule.note
          ? `${rule.note}（${field}: ${value} → ${rule.to}: ${mapped}）`
          : `${field}: ${value} → ${rule.to}: ${mapped}`,
        where: `${where}#${field}`,
      });
      continue;
    }

    out[rule.to] = value;
    if (rule.lossy) {
      findings.push({
        level: 'LOSS',
        code: 'frontmatter.field-lossy',
        message: rule.note ?? `${field} → ${rule.to} 为有损映射`,
        where: `${where}#${field}`,
      });
    }
  }

  return { content: matter.stringify(parsed.content, out), findings };
}
```

```typescript
import type { Finding } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import type { RemapResult } from './frontmatter.js';

function escapeRegExp(literal: string): string {
  return literal.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

export function substitutePathVars(
  content: string,
  from: EcosystemProfile,
  to: EcosystemProfile,
  where: string,
): RemapResult {
  const variable = from.pathVar;
  if (!variable) return { content, findings: [] };

  const strategy = to.pathVarStrategy;
  if (strategy.kind === 'keep') return { content, findings: [] };

  const findings: Finding[] = [];
  // 变量后面跟 "/xxx" 时连斜杠一起吃掉；单独出现时替换为 "."
  const pattern = new RegExp(`${escapeRegExp(variable)}(/)?`, 'g');

  const next = content.replace(pattern, (_match, slash: string | undefined) => {
    if (strategy.kind === 'rename') {
      findings.push({
        level: 'INFO',
        code: 'pathvar.renamed',
        message: `${variable} → ${strategy.to}`,
        where,
      });
      return slash ? `${strategy.to}/` : strategy.to;
    }
    findings.push({
      level: 'LOSS',
      code: 'pathvar.relativized',
      message: `${to.id} 没有插件根变量，${variable} 被改写为相对路径；若技能在其他工作目录下执行，该路径可能失效`,
      where,
    });
    return slash ? '' : '.';
  });

  return { content: next, findings };
}
```

```typescript
import { readFile, readdir, stat } from 'node:fs/promises';
import { join } from 'node:path';
import type { CapabilityDir, Finding, PluginIR } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import type { EmittedFile, ProjectionResult } from './types.js';
import { projectManifest } from './manifest.js';
import { remapFrontmatter, type FrontmatterKind } from './frontmatter.js';
import { substitutePathVars } from './pathvars.js';
import { loadProfile } from '../profiles/loader.js';

export type { EmittedFile, ProjectionResult } from './types.js';

/** 只投影清单，不读正文。保留给单测与 doctor 使用 */
export function project(ir: PluginIR, target: EcosystemProfile): ProjectionResult {
  const { manifest, files, findings } = projectManifest(ir, target);
  return { manifest, manifestPath: target.manifestPaths[0], files, findings };
}

/** 完整投影：清单 + 所有需要改写的正文文件 */
export async function projectAll(
  ir: PluginIR,
  target: EcosystemProfile,
): Promise<ProjectionResult> {
  const base = project(ir, target);
  const from = loadProfile(ir.sourceEcosystem);
  const files: EmittedFile[] = [...base.files];
  const findings: Finding[] = [...base.findings];

  for (const kind of ['commands', 'agents'] as const) {
    const dir = ir.capabilities[kind];
    if (!dir) continue;
    for (const entry of dir.entries) {
      const rel = `${dir.path}${entry}`;
      const source = await readFile(join(ir.root, rel), 'utf8');
      const remapped = remapFrontmatter(source, kind as FrontmatterKind, from, target, rel);
      const substituted = substitutePathVars(remapped.content, from, target, rel);
      findings.push(...remapped.findings, ...substituted.findings);
      if (substituted.content !== source) {
        files.push({ path: rel, content: substituted.content });
      }
    }
  }

  const skills = ir.capabilities.skills;
  if (skills) {
    for (const rel of await listMarkdown(ir.root, skills)) {
      const source = await readFile(join(ir.root, rel), 'utf8');
      const substituted = substitutePathVars(source, from, target, rel);
      findings.push(...substituted.findings);
      if (substituted.content !== source) {
        files.push({ path: rel, content: substituted.content });
      }
    }
  }

  return { ...base, files, findings };
}

/** 递归列出某个能力目录下的所有 .md，返回相对插件根的路径 */
async function listMarkdown(root: string, dir: CapabilityDir): Promise<string[]> {
  const out: string[] = [];

  async function walk(rel: string): Promise<void> {
    const names = await readdir(join(root, rel));
    for (const name of names.sort()) {
      if (name.startsWith('.')) continue;
      const child = `${rel}${name}`;
      const info = await stat(join(root, child));
      if (info.isDirectory()) await walk(`${child}/`);
      else if (name.endsWith('.md')) out.push(child);
    }
  }

  await walk(dir.path);
  return out;
}
```

```typescript
import { readFile } from 'node:fs/promises';
import { join } from 'node:path';
import type { Finding, FindingLevel, PluginIR } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import { projectAll } from '../project/index.js';

const LEVEL_ORDER: Record<FindingLevel, number> = { BLOCK: 3, LOSS: 2, INFO: 1 };

export function worstLevel(findings: Finding[]): FindingLevel | null {
  let worst: FindingLevel | null = null;
  for (const f of findings) {
    if (!worst || LEVEL_ORDER[f.level] > LEVEL_ORDER[worst]) worst = f.level;
  }
  return worst;
}

export async function doctor(ir: PluginIR, target?: EcosystemProfile): Promise<Finding[]> {
  const findings: Finding[] = [...ir.issues];

  for (const p of ir.provenance) {
    if (p.source !== 'manifest') {
      findings.push({
        level: 'INFO',
        code: 'provenance.inferred',
        message: `${p.field} 来自${p.source === 'convention' ? '目录约定' : 'profile 默认值'}，清单未显式声明${p.detail ? `（${p.detail}）` : ''}`,
        where: p.field,
      });
    }
  }

  findings.push(...(await checkInlineBash(ir)));

  if (!target) return findings;

  findings.push(...(await projectAll(ir, target)).findings);

  if (target.namePattern && !new RegExp(target.namePattern).test(ir.identity.name)) {
    findings.push({
      level: 'BLOCK',
      code: `${target.id}.name.pattern`,
      message: `name "${ir.identity.name}" 不满足 ${target.id} 的约束 ${target.namePattern}`,
      where: 'identity.name',
    });
  }

  if (target.id === 'codex' && ir.capabilities.agents) {
    findings.push({
      level: 'INFO',
      code: 'codex.agents.unverified',
      message:
        'Codex 侧未实测到 agents/ 目录约定，agents 会被原样拷贝但是否生效未经验证（spec 待确认 #1）',
      where: ir.capabilities.agents.path,
    });
  }

  const budget = target.limits.totalInstructionBytes;
  if (budget) {
    const projected = await projectAll(ir, target);
    const instructions = projected.manifest.skillInstructions;
    if (typeof instructions === 'string') {
      const size = Buffer.byteLength(instructions, 'utf8');
      // 单插件占满总预算的一半以上时预警：多插件同时启用会互相挤占
      if (size * 2 > budget) {
        findings.push({
          level: 'LOSS',
          code: `${target.id}.instruction-budget`,
          message: `skillInstructions 占 ${size} 字节，超过 ${target.id} 全局指令预算 ${budget} 的一半，与其他插件同时启用时可能被截断`,
          where: 'runtime.skillInstructions',
        });
      }
    }
  }

  return findings;
}

/** Claude command 支持 !`cmd` 内联 bash；目标端是否支持未经实测，先按有损处理 */
async function checkInlineBash(ir: PluginIR): Promise<Finding[]> {
  const dir = ir.capabilities.commands;
  if (!dir) return [];
  const out: Finding[] = [];
  for (const entry of dir.entries) {
    const rel = `${dir.path}${entry}`;
    const text = await readFile(join(ir.root, rel), 'utf8');
    if (/!`[^`]+`/.test(text)) {
      out.push({
        level: 'LOSS',
        code: 'command.inline-bash',
        message: '命令正文含内联 bash（!`cmd`），目标端是否支持未经实测（spec 待确认 #3）',
        where: rel,
      });
    }
  }
  return out;
}
```

```typescript
import type { Finding, FindingLevel } from '../ir/types.js';

const ORDER: FindingLevel[] = ['BLOCK', 'LOSS', 'INFO'];

const HEADINGS: Record<FindingLevel, string> = {
  BLOCK: 'BLOCK  目标端结构上无法承载，安装会失败或插件不可用',
  LOSS: 'LOSS   能转换但有损，以下内容在目标端会丢失或改变语义',
  INFO: 'INFO   供参考：目标端独有字段留空、字段值由推断得出',
};

export function formatFindings(findings: Finding[]): string {
  if (findings.length === 0) return '未发现问题。\n';

  const lines: string[] = [];
  for (const level of ORDER) {
    const group = findings.filter((f) => f.level === level);
    if (group.length === 0) continue;
    lines.push(`${HEADINGS[level]}（${group.length}）`);
    for (const f of group) {
      lines.push(`  · [${f.code}] ${f.message}${f.where ? `  — ${f.where}` : ''}`);
    }
    lines.push('');
  }
  return lines.join('\n');
}
```

```typescript
import { cp, mkdir, readdir, rm, writeFile } from 'node:fs/promises';
import { dirname, join } from 'node:path';
import type { PluginIR } from '../ir/types.js';
import type { ProjectionResult } from '../project/types.js';
import { loadProfile, ALL_PROFILE_IDS } from '../profiles/loader.js';

const ALWAYS_SKIP = new Set(['.git', 'node_modules', '.DS_Store', '.in_use']);

/** 所有生态的清单路径首段，转换时一律不带过去 */
function manifestTopSegments(): Set<string> {
  const out = new Set<string>();
  for (const id of ALL_PROFILE_IDS) {
    for (const rel of loadProfile(id).manifestPaths) {
      out.add(rel.split('/')[0]);
    }
  }
  return out;
}

export async function emit(
  ir: PluginIR,
  result: ProjectionResult,
  outDir: string,
): Promise<string[]> {
  await rm(outDir, { recursive: true, force: true });
  await mkdir(outDir, { recursive: true });

  const skip = new Set([...ALWAYS_SKIP, ...manifestTopSegments()]);

  for (const name of await readdir(ir.root)) {
    if (skip.has(name)) continue;
    await cp(join(ir.root, name), join(outDir, name), { recursive: true });
  }

  const written: string[] = [];

  for (const file of result.files) {
    const abs = join(outDir, file.path);
    await mkdir(dirname(abs), { recursive: true });
    await writeFile(abs, file.content, 'utf8');
    written.push(file.path);
  }

  const manifestAbs = join(outDir, result.manifestPath);
  await mkdir(dirname(manifestAbs), { recursive: true });
  await writeFile(manifestAbs, `${JSON.stringify(result.manifest, null, 2)}\n`, 'utf8');
  written.push(result.manifestPath);

  return written;
}
```

`rm(outDir, {recursive:true, force:true})` 是有意的：转换是幂等产物，重跑必须得到干净结果，不能留上一次的残渣。因此 `convert -o` 的目标目录必须是 scion 自己管的路径或用户显式指定的空目录——CLI 层要在这里加一道保护。

```typescript
import { parseArgs } from 'node:util';
import { homedir } from 'node:os';
import { join, resolve } from 'node:path';
import { readdir } from 'node:fs/promises';
import type { CliIo } from '../cli.js';
import { normalize } from '../normalize/index.js';
import { loadProfile } from '../profiles/loader.js';
import { projectAll } from '../project/index.js';
import { emit } from '../emit/write.js';
import { doctor, worstLevel } from '../doctor/index.js';
import { formatFindings } from '../doctor/report.js';
import { parseEcosystem } from './doctor.js';

/** scion 自己的输出根：~/.scion/out/<plugin>/<target>/ */
export function defaultOutDir(plugin: string, target: string): string {
  return join(homedir(), '.scion', 'out', plugin, target);
}

async function assertSafeOutDir(dir: string): Promise<void> {
  const scionRoot = join(homedir(), '.scion');
  if (resolve(dir).startsWith(scionRoot)) return;
  let entries: string[];
  try {
    entries = await readdir(dir);
  } catch {
    return; // 不存在 → 安全
  }
  if (entries.length > 0) {
    throw new Error(
      `refusing to overwrite non-empty directory ${dir}; pass an empty path or omit -o to use ~/.scion/out/`,
    );
  }
}

export async function runConvert(argv: string[], io: CliIo): Promise<number> {
  const { positionals, values } = parseArgs({
    args: argv,
    options: {
      to: { type: 'string' },
      from: { type: 'string', default: 'claude' },
      out: { type: 'string', short: 'o' },
    },
    allowPositionals: true,
  });

  const dir = positionals[0];
  if (!dir || !values.to) {
    io.write('usage: scion convert <dir> --to kimi|codex [-o <dir>] [--from claude]\n');
    return 1;
  }

  const source = loadProfile(parseEcosystem(values.from as string));
  const target = loadProfile(parseEcosystem(values.to));
  const ir = await normalize(dir, source);

  const findings = await doctor(ir, target);
  io.write(formatFindings(findings));
  if (worstLevel(findings) === 'BLOCK') {
    io.write('存在 BLOCK 项，已中止转换。\n');
    return 2;
  }

  const outDir = values.out ?? defaultOutDir(ir.identity.name, target.id);
  await assertSafeOutDir(outDir);
  const written = await emit(ir, await projectAll(ir, target), outDir);

  io.write(`已写出 ${written.length} 个文件到 ${outDir}\n`);
  return 0;
}
```

```typescript
export interface ManifestDiff {
  onlyGenerated: string[];
  onlyHandWritten: string[];
  differing: Array<{ field: string; generated: unknown; handWritten: unknown }>;
}

function diffManifests(
  generated: Record<string, unknown>,
  handWritten: Record<string, unknown>,
): ManifestDiff {
  const fields = new Set([...Object.keys(generated), ...Object.keys(handWritten)]);
  const diff: ManifestDiff = { onlyGenerated: [], onlyHandWritten: [], differing: [] };
  for (const field of [...fields].sort()) {
    const a = generated[field];
    const b = handWritten[field];
    if (a !== undefined && b === undefined) diff.onlyGenerated.push(field);
    else if (a === undefined && b !== undefined) diff.onlyHandWritten.push(field);
    else if (JSON.stringify(a) !== JSON.stringify(b)) {
      diff.differing.push({ field, generated: a, handWritten: b });
    }
  }
  return diff;
}
```

```typescript
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const execFileAsync = promisify(execFile);

export type Runner = (cmd: string, args: string[]) => Promise<{ stdout: string; stderr: string }>;

/** 用 execFile 而不是 exec：参数以数组传入，不经 shell，杜绝注入与引号问题 */
export const execRunner: Runner = async (cmd, args) => {
  const { stdout, stderr } = await execFileAsync(cmd, args, { encoding: 'utf8' });
  return { stdout, stderr };
};

export async function runOrThrow(run: Runner, cmd: string, args: string[]): Promise<string> {
  try {
    const { stdout } = await run(cmd, args);
    return stdout;
  } catch (err) {
    const e = err as Error & { stderr?: string };
    throw new Error(
      `command failed: ${cmd} ${args.join(' ')}\n${e.stderr?.trim() || e.message}`,
    );
  }
}
```

```typescript
import { mkdir, readFile, writeFile } from 'node:fs/promises';
import { join } from 'node:path';

export interface MarketplacePluginEntry {
  name: string;
  source: { source: 'local'; path: string };
  policy: { installation: 'AVAILABLE'; authentication: 'ON_INSTALL' };
  category: string;
}

interface MarketplaceFile {
  name: string;
  interface: { displayName: string };
  plugins: MarketplacePluginEntry[];
}

/** 与实测的 openai-bundled / team-skills 布局一致 */
const MANIFEST_REL = '.agents/plugins/marketplace.json';

export async function upsertMarketplaceEntry(
  marketplaceRoot: string,
  marketplaceName: string,
  entry: { name: string; category?: string },
): Promise<void> {
  const abs = join(marketplaceRoot, MANIFEST_REL);

  let file: MarketplaceFile;
  try {
    file = JSON.parse(await readFile(abs, 'utf8')) as MarketplaceFile;
  } catch {
    file = {
      name: marketplaceName,
      interface: { displayName: 'Scion' },
      plugins: [],
    };
  }

  const next: MarketplacePluginEntry = {
    name: entry.name,
    source: { source: 'local', path: `./plugins/${entry.name}` },
    policy: { installation: 'AVAILABLE', authentication: 'ON_INSTALL' },
    category: entry.category ?? 'Developer Tools',
  };

  const index = file.plugins.findIndex((p) => p.name === entry.name);
  if (index >= 0) file.plugins[index] = next;
  else file.plugins.push(next);

  await mkdir(join(marketplaceRoot, '.agents/plugins'), { recursive: true });
  await writeFile(abs, `${JSON.stringify(file, null, 2)}\n`, 'utf8');
}
```

`src/install/codex.ts`：

```typescript
import { join } from 'node:path';
import type { EcosystemId, PluginIR } from '../ir/types.js';
import { loadProfile } from '../profiles/loader.js';
import { projectAll } from '../project/index.js';
import { emit } from '../emit/write.js';
import { upsertMarketplaceEntry } from './marketplace.js';
import { execRunner, runOrThrow, type Runner } from './exec.js';

export interface InstallOutcome {
  target: EcosystemId;
  /** 转换产物落地的目录 */
  pluginRoot: string;
  /** 实际执行过的外部命令，供 --dry-run 与日志使用 */
  commands: string[][];
  /** 是否已在目标生态完成注册 */
  registered: boolean;
  /** 未注册时给用户的下一步指引 */
  note?: string;
}

export async function installToCodex(
  ir: PluginIR,
  opts: { home: string; run?: Runner },
): Promise<InstallOutcome> {
  const profile = loadProfile('codex');
  const strategy = profile.install.strategy;
  if (strategy.kind !== 'codex-cli') throw new Error('codex profile must use the codex-cli strategy');

  const run = opts.run ?? execRunner;
  const marketplaceRoot = join(opts.home, strategy.marketplaceRoot);
  const pluginRoot = join(marketplaceRoot, 'plugins', ir.identity.name);

  await emit(ir, await projectAll(ir, profile), pluginRoot);
  await upsertMarketplaceEntry(marketplaceRoot, strategy.marketplaceName, {
    name: ir.identity.name,
    category: ir.presentation.category,
  });

  const commands: string[][] = [
    ['codex', 'plugin', 'marketplace', 'add', marketplaceRoot],
    ['codex', 'plugin', 'add', `${ir.identity.name}@${strategy.marketplaceName}`],
  ];

  for (const [cmd, ...args] of commands) {
    await runOrThrow(run, cmd, args);
  }

  return { target: 'codex', pluginRoot, commands, registered: true };
}
```

```typescript
import { dirname } from 'node:path';

/** 备份既有文件；文件不存在时返回 null */
export async function backupFile(path: string, stamp: string): Promise<string | null> {
  const backup = `${path}.scion-bak.${stamp}`;
  try {
    await copyFile(path, backup);
    return backup;
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === 'ENOENT') return null;
    throw err;
  }
}

export async function atomicWriteJson(path: string, value: unknown): Promise<void> {
  await mkdir(dirname(path), { recursive: true });
  const temp = `${path}.scion-tmp`;
  await writeFile(temp, `${JSON.stringify(value, null, 2)}\n`, 'utf8');
  await rename(temp, path);
}
```

```typescript
import { readFile } from 'node:fs/promises';
import { join } from 'node:path';
import type { PluginIR } from '../ir/types.js';
import { loadProfile } from '../profiles/loader.js';
import { projectAll } from '../project/index.js';
import { emit } from '../emit/write.js';
import { atomicWriteJson, backupFile } from './atomic.js';
import type { InstallOutcome } from './codex.js';

interface KimiRegistryEntry {
  id: string;
  root: string;
  source: string;
  enabled: boolean;
  installedAt: string;
  updatedAt: string;
  originalSource: string;
}

interface KimiRegistry {
  version: number;
  plugins: KimiRegistryEntry[];
}

export async function installToKimi(
  ir: PluginIR,
  opts: { home: string; writeRegistry?: boolean; now?: () => Date },
): Promise<InstallOutcome> {
  const profile = loadProfile('kimi');
  const strategy = profile.install.strategy;
  if (strategy.kind !== 'kimi-managed') throw new Error('kimi profile must use the kimi-managed strategy');

  const now = (opts.now ?? (() => new Date()))();
  const projected = await projectAll(ir, profile);

  if (!opts.writeRegistry) {
    const outDir = join(opts.home, '.scion', 'out', ir.identity.name, 'kimi');
    await emit(ir, projected, outDir);
    return {
      target: 'kimi',
      pluginRoot: outDir,
      commands: [],
      registered: false,
      note: `Kimi 没有提供插件管理 CLI。转换产物已写到 ${outDir}；请在 Kimi 里运行 /plugins，从该本地路径安装。若确实要让 scion 代写注册表，重跑并加 --write-registry。`,
    };
  }

  const pluginRoot = join(opts.home, strategy.rootTemplate.replace('<plugin>', ir.identity.name));
  await emit(ir, projected, pluginRoot);

  const registryPath = join(opts.home, strategy.registryPath);
  const stamp = now.toISOString().replace(/[:.]/g, '-');
  await backupFile(registryPath, stamp);

  let registry: KimiRegistry;
  try {
    registry = JSON.parse(await readFile(registryPath, 'utf8')) as KimiRegistry;
  } catch {
    registry = { version: 1, plugins: [] };
  }
  if (!Array.isArray(registry.plugins)) registry.plugins = [];

  const iso = now.toISOString();
  const index = registry.plugins.findIndex((p) => p.id === ir.identity.name);
  const previous = index >= 0 ? registry.plugins[index] : undefined;
  const entry: KimiRegistryEntry = {
    id: ir.identity.name,
    root: pluginRoot,
    source: 'local-path',
    enabled: previous?.enabled ?? true,
    installedAt: previous?.installedAt ?? iso,
    updatedAt: iso,
    originalSource: ir.root,
  };
  if (index >= 0) registry.plugins[index] = entry;
  else registry.plugins.push(entry);

  await atomicWriteJson(registryPath, registry);

  return {
    target: 'kimi',
    pluginRoot,
    commands: [],
    registered: true,
    note: `已写入 ${registryPath}（原文件已备份）。重启 Kimi 会话后生效。`,
  };
}
```

```typescript
import { mkdir, rm, stat } from 'node:fs/promises';
import { join, resolve } from 'node:path';
import { execRunner, runOrThrow, type Runner } from '../install/exec.js';

export interface ResolvedSource {
  dir: string;
  kind: 'path' | 'zip' | 'git';
  original: string;
  ref?: string;
}

const GIT_URL = /^(https?:\/\/|git@|ssh:\/\/)/;
const SHORTHAND = /^[\w.-]+\/[\w.-]+$/;

/** 把 URL 压成一个可用作目录名的 slug */
export function sourceSlug(url: string): string {
  return url
    .replace(/^https?:\/\//, '')
    .replace(/\.git$/, '')
    .replace(/[^\w.-]+/g, '_');
}

export async function resolveSource(
  spec: string,
  opts: { home: string; run?: Runner },
): Promise<ResolvedSource> {
  const run = opts.run ?? execRunner;

  const asPath = resolve(spec);
  let info: Awaited<ReturnType<typeof stat>> | null = null;
  try {
    info = await stat(asPath);
  } catch {
    info = null;
  }

  if (info?.isDirectory()) return { dir: spec, kind: 'path', original: spec };

  if (info?.isFile() && spec.endsWith('.zip')) {
    const dir = join(opts.home, '.scion', 'src', sourceSlug(spec));
    await rm(dir, { recursive: true, force: true });
    await mkdir(dir, { recursive: true });
    // macOS / Linux 均自带 unzip；避免为此引入依赖
    await runOrThrow(run, 'unzip', ['-q', asPath, '-d', dir]);
    return { dir, kind: 'zip', original: spec };
  }

  const url = GIT_URL.test(spec)
    ? spec
    : SHORTHAND.test(spec)
      ? `https://github.com/${spec}.git`
      : null;

  if (url) {
    const dir = join(opts.home, '.scion', 'src', sourceSlug(url));
    await rm(dir, { recursive: true, force: true });
    await mkdir(join(opts.home, '.scion', 'src'), { recursive: true });
    await runOrThrow(run, 'git', ['clone', '--depth', '1', url, dir]);
    return { dir, kind: 'git', original: spec };
  }

  throw new Error(`cannot resolve source '${spec}' (expected a directory, a .zip, owner/repo, or a git URL)`);
}
```

`src/commands/install.ts`：

```typescript
import { parseArgs } from 'node:util';
import { homedir } from 'node:os';
import type { CliIo } from '../cli.js';
import type { EcosystemId } from '../ir/types.js';
import type { Runner } from '../install/exec.js';
import { normalize } from '../normalize/index.js';
import { loadProfile } from '../profiles/loader.js';
import { doctor, worstLevel } from '../doctor/index.js';
import { formatFindings } from '../doctor/report.js';
import { resolveSource } from '../source/resolve.js';
import { installToCodex, type InstallOutcome } from '../install/codex.js';
import { installToKimi } from '../install/kimi.js';
import { parseEcosystem } from './doctor.js';

export interface InstallDeps {
  home?: string;
  run?: Runner;
}

export async function runInstall(
  argv: string[],
  io: CliIo,
  deps: InstallDeps = {},
): Promise<number> {
  const { positionals, values } = parseArgs({
    args: argv,
    options: {
      to: { type: 'string' },
      from: { type: 'string', default: 'claude' },
      yes: { type: 'boolean', default: false },
      'write-registry': { type: 'boolean', default: false },
    },
    allowPositionals: true,
  });

  const spec = positionals[0];
  if (!spec || !values.to) {
    io.write('usage: scion install <github|path|zip> --to kimi[,codex] [--yes] [--write-registry]\n');
    return 1;
  }

  const home = deps.home ?? homedir();
  const targets = (values.to as string).split(',').map((t) => parseEcosystem(t.trim()));
  const source = loadProfile(parseEcosystem(values.from as string));

  const resolved = await resolveSource(spec, { home, run: deps.run });
  const ir = await normalize(resolved.dir, source);

  for (const target of targets) {
    const findings = await doctor(ir, loadProfile(target));
    io.write(`\n${ir.identity.name} · ${source.id} → ${target}\n`);
    io.write(formatFindings(findings));

    const worst = worstLevel(findings);
    if (worst === 'BLOCK') {
      io.write(`存在 BLOCK 项，未安装到 ${target}。\n`);
      return 2;
    }
    if (worst === 'LOSS' && !values.yes) {
      io.write('存在 LOSS 项。确认接受这些损耗后，重跑并加 --yes。\n');
      return 3;
    }
  }

  for (const target of targets) {
    const outcome = await install(target, ir, {
      home,
      run: deps.run,
      writeRegistry: values['write-registry'] as boolean,
    });
    io.write(`\n[${target}] ${outcome.registered ? '已安装' : '已转换'} → ${outcome.pluginRoot}\n`);
    if (outcome.note) io.write(`${outcome.note}\n`);
  }

  return 0;
}

function install(
  target: EcosystemId,
  ir: Parameters<typeof installToCodex>[0],
  opts: { home: string; run?: Runner; writeRegistry: boolean },
): Promise<InstallOutcome> {
  switch (target) {
    case 'codex':
      return installToCodex(ir, { home: opts.home, run: opts.run });
    case 'kimi':
      return installToKimi(ir, { home: opts.home, writeRegistry: opts.writeRegistry });
    case 'claude':
      throw new Error(loadProfile('claude').install.strategy.kind === 'unsupported'
        ? 'v1 不支持安装到 Claude（Claude 只作为转换源）'
        : 'unreachable');
  }
}
```

在 `src/cli.ts` 的 switch 里加 `case 'install': return runInstall(rest, io);`。

**注意：** doctor 循环与安装循环是分开的两遍——所有目标都通过检查后才动手安装，避免"装了一半发现第二个目标 BLOCK"的半成品状态。

```typescript
export interface InstallRecord {
  name: string;
  version?: string;
  target: EcosystemId;
  source: string;
  sourceKind: 'path' | 'zip' | 'git';
  pluginRoot: string;
  registered: boolean;
  installedAt: string;
  updatedAt: string;
}

interface StateFile {
  version: number;
  installs: InstallRecord[];
}

function statePath(home: string): string {
  return join(home, '.scion', 'installed.json');
}

export async function readState(home: string): Promise<InstallRecord[]> {
  try {
    const file = JSON.parse(await readFile(statePath(home), 'utf8')) as StateFile;
    return Array.isArray(file.installs) ? file.installs : [];
  } catch {
    return [];
  }
}

export async function recordInstall(
  home: string,
  record: Omit<InstallRecord, 'installedAt' | 'updatedAt'>,
  now: () => Date = () => new Date(),
): Promise<void> {
  const installs = await readState(home);
  const iso = now().toISOString();
  const index = installs.findIndex((r) => r.name === record.name && r.target === record.target);
  const previous = index >= 0 ? installs[index] : undefined;
  const next: InstallRecord = {
    ...record,
    installedAt: previous?.installedAt ?? iso,
    updatedAt: iso,
  };
  if (index >= 0) installs[index] = next;
  else installs.push(next);

  await atomicWriteJson(statePath(home), { version: 1, installs });
}
```

```typescript
import { homedir } from 'node:os';
import type { CliIo } from '../cli.js';
import { readState } from '../install/state.js';
import { runInstall, type InstallDeps } from './install.js';

export async function runSync(
  argv: string[],
  io: CliIo,
  deps: InstallDeps = {},
): Promise<number> {
  const home = deps.home ?? homedir();
  const only = argv[0];
  const records = (await readState(home)).filter((r) => !only || r.name === only);

  if (records.length === 0) {
    io.write(only ? `未找到已安装的 ${only}。\n` : '没有需要同步的插件。\n');
    return only ? 1 : 0;
  }

  // 同一来源的多个目标合并成一次 install，避免重复拉取
  const bySource = new Map<string, typeof records>();
  for (const r of records) {
    const list = bySource.get(r.source) ?? [];
    list.push(r);
    bySource.set(r.source, list);
  }

  for (const [source, group] of bySource) {
    const targets = [...new Set(group.map((r) => r.target))].join(',');
    const registered = group.some((r) => r.registered);
    io.write(`同步 ${group[0].name}（${source} → ${targets}）\n`);
    const args = ['--to', targets, '--yes', ...(registered ? ['--write-registry'] : []), source];
    const code = await runInstall(args, io, { ...deps, home });
    if (code !== 0) return code;
  }
  return 0;
}
```

`src/marketplace/normalize.ts`：

```typescript
import { readFile, stat } from 'node:fs/promises';
import { basename, dirname, join, resolve } from 'node:path';
import type { EcosystemProfile } from '../profiles/types.js';
import type { MarketplaceEntryIR, MarketplaceIR } from './types.js';

function isRemote(source: string): boolean {
  return /^(https?:\/\/|git@|ssh:\/\/)/.test(source);
}

function str(record: Record<string, unknown>, ...keys: string[]): string | undefined {
  for (const key of keys) {
    if (typeof record[key] === 'string') return record[key] as string;
  }
  return undefined;
}

/** target 既可以是 marketplace 根目录，也可以直接是 catalog 文件 */
async function locateCatalog(
  target: string,
  profile: EcosystemProfile,
): Promise<{ catalogPath: string; root: string } | null> {
  const abs = resolve(target);
  const info = await stat(abs).catch(() => null);

  if (info?.isFile()) {
    const rel = profile.marketplaceDialect.catalogPaths.find((p) => abs.endsWith(p));
    // 直接给文件时，root 是去掉 catalog 相对路径后的那一层
    const root = rel ? abs.slice(0, abs.length - rel.length - 1) : dirname(abs);
    return { catalogPath: abs, root: root || dirname(abs) };
  }

  for (const rel of profile.marketplaceDialect.catalogPaths) {
    const candidate = join(abs, rel);
    if ((await stat(candidate).catch(() => null))?.isFile()) {
      return { catalogPath: candidate, root: abs };
    }
  }
  return null;
}

export async function normalizeMarketplace(
  target: string,
  profile: EcosystemProfile,
): Promise<MarketplaceIR> {
  const dialect = profile.marketplaceDialect;
  const located = await locateCatalog(target, profile);
  if (!located) {
    throw new Error(
      `no ${profile.id} marketplace catalog found at ${target} (looked for: ${dialect.catalogPaths.join(', ')})`,
    );
  }

  let raw: Record<string, unknown>;
  try {
    raw = JSON.parse(await readFile(located.catalogPath, 'utf8')) as Record<string, unknown>;
  } catch (err) {
    throw new Error(`failed to parse ${basename(located.catalogPath)}: ${(err as Error).message}`);
  }

  const mp: MarketplaceIR = {
    root: located.root,
    catalogPath: located.catalogPath,
    sourceEcosystem: profile.id,
    name: null,
    entries: [],
    provenance: [],
    issues: [],
  };

  if (dialect.nameField && typeof raw[dialect.nameField] === 'string') {
    mp.name = raw[dialect.nameField] as string;
    mp.provenance.push({ field: 'marketplace.name', source: 'manifest', detail: dialect.nameField });
  }

  if (typeof raw.version === 'string') mp.version = raw.version;

  if (dialect.ownerField === 'owner') {
    const owner = raw.owner;
    if (owner && typeof owner === 'object') {
      mp.owner = { name: str(owner as Record<string, unknown>, 'name') };
    }
  } else if (dialect.ownerField === 'interface') {
    const iface = raw.interface;
    if (iface && typeof iface === 'object') {
      mp.displayName = str(iface as Record<string, unknown>, 'displayName');
    }
  }

  const plugins = raw.plugins;
  if (!Array.isArray(plugins)) {
    mp.issues.push({
      level: 'BLOCK',
      code: 'marketplace.no-plugins',
      message: 'catalog 缺少 plugins 数组',
      where: located.catalogPath,
    });
    return mp;
  }

  plugins.forEach((value, index) => {
    if (!value || typeof value !== 'object' || Array.isArray(value)) {
      mp.issues.push({
        level: 'BLOCK',
        code: 'marketplace.entry-invalid',
        message: `第 ${index + 1} 个条目不是对象`,
        where: located.catalogPath,
      });
      return;
    }
    const entry = value as Record<string, unknown>;
    const name = str(entry, dialect.entryKeyField);
    const source =
      dialect.entrySourceForm === 'object'
        ? str((entry.source ?? {}) as Record<string, unknown>, 'path')
        : str(entry, 'source', 'url', 'downloadUrl');

    if (!name || !source) {
      mp.issues.push({
        level: 'BLOCK',
        code: 'marketplace.entry-invalid',
        message: `第 ${index + 1} 个条目缺少 ${!name ? dialect.entryKeyField : 'source'}`,
        where: located.catalogPath,
      });
      return;
    }

    const out: MarketplaceEntryIR = {
      name,
      sourcePath: source,
      sourceKind: isRemote(source) ? 'remote' : 'local',
    };
    out.displayName = str(entry, 'displayName');
    out.description = str(entry, 'description', 'shortDescription');
    out.version = str(entry, 'version');
    out.homepage = str(entry, 'homepage', 'websiteURL');
    out.category = str(entry, 'category');
    if (Array.isArray(entry.keywords)) {
      out.keywords = entry.keywords.filter((k): k is string => typeof k === 'string');
    }
    mp.entries.push(out);
  });

  return mp;
}
```

### Task 23: Marketplace 投影与落盘（保留原市场名）

**Files:**

- Test: `tests/marketplace-project.test.ts`

**Interfaces:**
- Consumes: `MarketplaceIR`（Task 22）、`normalize` / `projectAll` / `emit`（Task 7、14、16）
- Produces:
  - `function projectMarketplace(mp: MarketplaceIR, target: EcosystemProfile): { catalog: Record<string, unknown>; catalogPath: string; findings: Finding[] }`
  - `function emitMarketplace(mp: MarketplaceIR, target: EcosystemProfile, outDir: string): Promise<{ catalogPath: string; converted: string[]; findings: Finding[] }>`

落盘布局：`<outDir>/<catalogPath>` 写 catalog，每个 **local** 条目的插件转换后写到 `<outDir>/plugins/<name>/`，条目 source 相应指向 `./plugins/<name>`。remote 条目（`url` / `git-subdir`）原样保留 source，不去拉取——那属于 spec 明确排除的"镜像市场/批量搬运"，而且两个目标生态都能表达远端来源，无需本地化。

**两个生态各自都需要完整的 `plugins/` 目录，不能共用一份。** Kimi 的 `resolveEntrySource`（实测其二进制）对非 `http(s)://`、非绝对路径的 source，一律按相对路径解析到 **catalog 文件所在目录**——所以 `kimi/` 下只有一个 `marketplace.json` 是不成立的，本地条目必须有真实存在的插件目录躺在它旁边。而且两侧的插件产物**内容不同**（清单格式不同、Kimi 侧还注入了 `skillInstructions`），因此必须各转一份：

```
~/.scion/markets/<市场名>/
├── codex/
│   ├── .agents/plugins/marketplace.json
│   └── plugins/<插件>/          ← Codex 版转换产物
```

```typescript
import { mkdir, writeFile } from 'node:fs/promises';
import { dirname, join } from 'node:path';
import type { Finding } from '../ir/types.js';
import type { EcosystemProfile } from '../profiles/types.js';
import type { MarketplaceEntryIR, MarketplaceIR } from './types.js';
import { normalize } from '../normalize/index.js';
import { projectAll } from '../project/index.js';
import { emit } from '../emit/write.js';
import { loadProfile } from '../profiles/loader.js';

export interface MarketplaceProjection {
  catalog: Record<string, unknown>;
  /** 相对输出根的 catalog 路径 */
  catalogPath: string;
  findings: Finding[];
}

function projectEntry(
  entry: MarketplaceEntryIR,
  target: EcosystemProfile,
  findings: Finding[],
): Record<string, unknown> {
  const dialect = target.marketplaceDialect;
  const out: Record<string, unknown> = {};

  out[dialect.entryKeyField] = entry.name;

  // entrySourceForm 在这里（写出时）才有意义；读取端按条目实际值的类型分派，不查它。
  if (dialect.entrySourceForm === 'object') {
    // 对象形态能完整表达三种来源，包括 git-subdir 的 path/ref/sha
    switch (entry.source.kind) {
      case 'local':
        out.source = { source: 'local', path: entry.source.path };
        break;
      case 'url':
        out.source = { source: 'url', url: entry.source.url };
        break;
      case 'git-subdir': {
        const s: Record<string, unknown> = { source: 'git-subdir', url: entry.source.url };
        if (entry.source.path !== undefined) s.path = entry.source.path;
        if (entry.source.ref !== undefined) s.ref = entry.source.ref;
        if (entry.source.sha !== undefined) s.sha = entry.source.sha;
        out.source = s;
        break;
      }
    }
  } else {
    // 字符串形态只能承载一个位置。git-subdir 的子目录与版本锁定无处安放——这是真损耗。
    switch (entry.source.kind) {
      case 'local':
        out.source = entry.source.path;
        break;
      case 'url':
        out.source = entry.source.url;
        break;
      case 'git-subdir':
        out.source = entry.source.url;
        findings.push({
          level: 'LOSS',
          code: 'marketplace.git-subdir-flattened',
          message:
            `${target.id} 的条目 source 只能是单个字符串，无法表达子目录与版本锁定；` +
            `条目 "${entry.name}" 的 path=${entry.source.path ?? '(无)'} / ` +
            `ref=${entry.source.ref ?? '(无)'} / sha=${entry.source.sha ?? '(无)'} 已丢失，` +
            `仅保留仓库地址。安装后取到的是该仓库默认分支的根目录，不是原本锁定的那份`,
          where: `plugins[].${entry.name}`,
        });
        break;
    }
  }

  const allowed = new Set(dialect.entryFields);
  if (allowed.has('displayName') && entry.displayName) out.displayName = entry.displayName;
  if (allowed.has('description') && entry.description) out.description = entry.description;
  if (allowed.has('version') && entry.version) out.version = entry.version;
  if (allowed.has('homepage') && entry.homepage) out.homepage = entry.homepage;
  if (allowed.has('keywords') && entry.keywords?.length) out.keywords = entry.keywords;
  if (allowed.has('policy')) {
    out.policy = { installation: 'AVAILABLE', authentication: 'ON_INSTALL' };
  }
  if (allowed.has('category')) out.category = entry.category ?? 'Developer Tools';

  return out;
}

export function projectMarketplace(
  mp: MarketplaceIR,
  target: EcosystemProfile,
): MarketplaceProjection {
  const dialect = target.marketplaceDialect;
  const findings: Finding[] = [...mp.issues];
  const catalog: Record<string, unknown> = {};

  if (dialect.nameField) {
    if (mp.name) catalog[dialect.nameField] = mp.name;
  } else if (mp.name) {
    findings.push({
      level: 'INFO',
      code: 'marketplace.name-not-carried',
      message: `${target.id} 的 catalog 格式没有市场名字段，"${mp.name}" 只体现在输出文件路径上`,
      where: 'marketplace.name',
    });
  }

  if (dialect.ownerField === 'owner' && mp.owner?.name) {
    catalog.owner = { name: mp.owner.name };
  } else if (dialect.ownerField === 'interface') {
    catalog.interface = { displayName: mp.displayName ?? mp.name ?? 'Marketplace' };
  }

  // 顶层字段用 catalogFields 判定，不能借用 entryFields——那是条目级白名单，判定轴不同
  if (dialect.catalogFields.includes('version') && mp.version) catalog.version = mp.version;

  catalog.plugins = mp.entries.map((entry) => projectEntry(entry, target, findings));

  return { catalog, catalogPath: dialect.catalogPaths[0], findings };
}

export interface MarketplaceEmitResult {
  catalogPath: string;
  /** 实际转换过的本地插件名 */
  converted: string[];
  findings: Finding[];
}

export async function emitMarketplace(
  mp: MarketplaceIR,
  target: EcosystemProfile,
  outDir: string,
): Promise<MarketplaceEmitResult> {
  const projection = projectMarketplace(mp, target);
  const findings: Finding[] = [...projection.findings];
  const converted: string[] = [];
  const source = loadProfile(mp.sourceEcosystem);

  for (const entry of mp.entries) {
    if (entry.source.kind !== 'local') {
      findings.push({
        level: 'INFO',
        code: 'marketplace.remote-entry-skipped',
        message: `条目 ${entry.name} 指向远端来源（${entry.source.kind}），未转换；source 原样保留，由目标生态自行拉取`,
        where: entry.source.url,
      });
      continue;
    }

    const pluginDir = join(mp.root, entry.source.path.replace(/^\.\//, ''));
    const ir = await normalize(pluginDir, source);
    const projected = await projectAll(ir, target);
    await emit(ir, projected, join(outDir, 'plugins', entry.name));
    converted.push(entry.name);
    findings.push(
      ...projected.findings.map((f) => ({ ...f, where: `${entry.name}:${f.where ?? ''}` })),
    );
  }

  // 本地条目一律改指向输出目录里的 plugins/<name>；远端条目（url / git-subdir）不动
  const entries = projection.catalog.plugins as Record<string, unknown>[];
  mp.entries.forEach((entry, index) => {
    if (entry.source.kind !== 'local') return;
    const projectedEntry = entries[index];
    const path = `./plugins/${entry.name}`;
    projectedEntry.source =
      target.marketplaceDialect.entrySourceForm === 'object'
        ? { source: 'local', path }
        : path;
  });

  const catalogAbs = join(outDir, projection.catalogPath);
  await mkdir(dirname(catalogAbs), { recursive: true });
  await writeFile(catalogAbs, `${JSON.stringify(projection.catalog, null, 2)}\n`, 'utf8');

  return { catalogPath: projection.catalogPath, converted, findings };
}
```

CLI 形态：


默认输出目录 `~/.scion/markets/<name>/<target>/`；Kimi 的 catalog 无市场名时，用源目录名兜底。

**`--as <name>` 与冲突检测（依据实测：Codex 的注册键取自 `marketplace.json` 的 `name` 字段）**

- 不传 `--as` 时，产物的市场名**保持原名**。模式 B（写回自己仓库）必须如此——产物就是那个市场本身，改名是错的。
- 传 `--as <name>` 时，把该名字写进产物的 `name` 字段（Kimi 的 catalog 无此字段，则只体现在输出路径上，并复用已有的 `marketplace.name-not-carried` INFO）。
- **转换到 Codex 且未传 `--as` 时**，先执行 `codex plugin marketplace list`，解析出已注册的市场名集合（两列输出，第一列无空格，按首个空白切分）。若产物的市场名已存在，**报 BLOCK 并中止**，提示用 `--as <name>` 改名或先移除原有注册。
  - `code: 'marketplace.name-conflict'`，message 里点明「Codex 的 config.toml 按名字做键，同名注册会覆盖既有条目」。
  - 该命令不可用时（未安装 codex 等）降级为 LOSS 而非 BLOCK，说明无法核对冲突，并照常产出文件——`market convert` 只产文件、不注册，所以无法核对不该阻断转换。
- 改名只能发生在转换时，不能延后到注册时：模式 A 与模式 B 要求同一字段取不同的值，一份产物无法同时满足两者。

补充测试：
- 未传 `--as` 时产物的 `name` 与源一致；
- 传 `--as` 时 Codex 产物的 `name` 被改写，且 `plugins[].source.path` 不受影响；
- 注入一个假的 runner 返回含同名市场的 `marketplace list` 输出，断言产出 `marketplace.name-conflict` BLOCK 且**未写出任何文件**；
- 同一假 runner 下传了 `--as` 且新名不冲突时正常产出。

```typescript
import { parseArgs } from 'node:util';
import { homedir } from 'node:os';
import { basename, join, resolve } from 'node:path';
import type { CliIo } from '../cli.js';
import { loadProfile } from '../profiles/loader.js';
import { normalizeMarketplace } from '../marketplace/normalize.js';
import { emitMarketplace, projectMarketplace } from '../marketplace/project.js';
import { formatFindings } from '../doctor/report.js';
import { worstLevel } from '../doctor/index.js';
import { parseEcosystem } from './doctor.js';

const USAGE = [
  'usage:',
  '  scion market convert <dir|json> --to codex|kimi [--from claude] [-o <dir>]',
  '  scion market show <dir|json> [--from claude]',
  '',
].join('\n');

export async function runMarket(
  argv: string[],
  io: CliIo,
  deps: { home?: string } = {},
): Promise<number> {
  const [sub, ...rest] = argv;
  if (sub !== 'convert' && sub !== 'show') {
    io.write(USAGE);
    return 1;
  }

  const { positionals, values } = parseArgs({
    args: rest,
    options: {
      to: { type: 'string' },
      from: { type: 'string', default: 'claude' },
      out: { type: 'string', short: 'o' },
    },
    allowPositionals: true,
  });

  const target0 = positionals[0];
  if (!target0) {
    io.write(USAGE);
    return 1;
  }

  const home = deps.home ?? homedir();
  const source = loadProfile(parseEcosystem(values.from as string));
  const mp = await normalizeMarketplace(target0, source);
  const marketName = mp.name ?? basename(resolve(mp.root));

  if (sub === 'show') {
    io.write(`marketplace: ${marketName}（${source.id}）\n`);
    io.write(`catalog: ${mp.catalogPath}\n`);
    io.write(`条目 ${mp.entries.length} 个：\n`);
    for (const e of mp.entries) {
      const loc = e.source.kind === 'local' ? e.source.path : e.source.url;
      io.write(`  · ${e.name}  [${e.source.kind}]  ${loc}\n`);
    }
    if (mp.issues.length > 0) io.write(`\n${formatFindings(mp.issues)}`);
    return 0;
  }

  if (!values.to) {
    io.write(USAGE);
    return 1;
  }
  const targetProfile = loadProfile(parseEcosystem(values.to));

  const preview = projectMarketplace(mp, targetProfile);
  if (worstLevel(preview.findings) === 'BLOCK') {
    io.write(formatFindings(preview.findings));
    io.write('存在 BLOCK 项，已中止。\n');
    return 2;
  }

  const outDir = values.out ?? join(home, '.scion', 'markets', marketName, targetProfile.id);
  const result = await emitMarketplace(mp, targetProfile, outDir);

  io.write(formatFindings(result.findings));
  io.write(
    `\n${marketName}: 已转换 ${result.converted.length} 个插件 → ${outDir}\n` +
      `catalog: ${join(outDir, result.catalogPath)}\n\n`,
  );

  if (targetProfile.id === 'codex') {
    io.write(
      '下一步（scion 不代为注册）：\n' +
        `  codex plugin marketplace add ${outDir}\n` +
        `  注意：Codex 的 config.toml 按名字做键，若已存在名为 "${marketName}" 的 marketplace，这条命令会覆盖它。\n`,
    );
  } else {
    io.write(
      '下一步（scion 不代为注册）：\n' +
        `  KIMI_CODE_PLUGIN_MARKETPLACE_URL=${join(outDir, result.catalogPath)} kimi\n` +
        '  或在 Kimi 里运行 /plugins <该路径>\n',
    );
  }

  return 0;
}
```
